Panduan Singkat Penggunaan

Mode Manual: Gunakan jempol kiri untuk maju/mundur dan jempol kanan untuk belok kiri/kanan. Saat tombol dilepas, robot otomatis berhenti.
Mode Otomatis: Robot berjalan mengikuti jalur garis hitam memakai 5 sensor di bagian bawah.
Kecepatan & PID: Geser slider untuk membatasi kecepatan motor, dan buka menu Atur PID jika gerakan belok di mode otomatis kurang halus.
Tombol STOP: Tekan kapan saja untuk langsung mematikan kedua motor.
